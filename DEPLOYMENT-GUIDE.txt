2. Extensions → Apps Script.
3. Replace the current code with AppsScript-Code.gs.
4. At the top, replace:
   CHANGE-THIS-TO-A-LONG-PRIVATE-ADMIN-KEY
   with a long private key known only to you.
5. Save.
6. Deploy → Manage deployments.
7. Edit the existing Web app deployment.
8. Choose New version.
9. Deploy.
10. Keep the same /exec URL.

The dashboard will not open until ADMIN_KEY is changed.

PERSONALIZED WHATSAPP VENUE ANNOUNCEMENTS
========================================
The dashboard now includes “Venue Announcements”.

Before using it:
1. Open Venue & Sharing.
2. Enter venue name, address, Google Maps URL and optional notes.
3. Enable “Venue announced”.
4. Save settings.

Then:
1. Open Venue Announcements.
2. Review each personalized message.
3. Click WhatsApp to open the guest’s chat with the message prefilled.
4. Press Send manually inside WhatsApp.
5. Return to the dashboard and click Mark Sent.

Features:
- Guest name in every message
- Adults and children count in every message
- Date, time, venue and directions
- Optional parking / arrival notes
- Automatic India country code for 10-digit numbers
- Pending / Sent tracking
- Send Next Pending
- Copy message
- Reset statuses

Important:
A normal webpage cannot press WhatsApp’s Send button automatically.
The final Send action must be completed manually unless a paid, approved
WhatsApp Business API integration is used.
